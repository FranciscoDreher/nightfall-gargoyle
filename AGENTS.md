# Game Agents

## Purpose
Shared instructions for AI agents working on a basic 2D Python game.

## General Rules
- Inspect the existing code before changing it.
- Prefer small, focused changes.
- Preserve working gameplay unless a change is explicitly requested.
- Do not rewrite systems unnecessarily.
- Avoid unrelated file changes.
- Keep game logic, rendering, input, and data reasonably separated.
- Do not create commits automatically.

## Workflow
1. Understand the request.
2. Inspect relevant files.
3. Make a short plan.
4. Implement the smallest appropriate change.
5. Run tests/checks when available.
6. Report what changed and any remaining concerns.
